使用流程

  1. 在「成员 / 暗号记录 / 批量导入」里增删改数据（改完会自动存本机草稿）
  2. 去「导出」页，点 下载 index.html 和 下载 db.json
  3. 把两个文件覆盖到仓库根目录，然后 git commit && git push
  4. GitHub Pages 会在 1~2 分钟内更新，所有人打开就是最新版
