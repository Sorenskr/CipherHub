# CipherHub · 暗号查询中心（正式版 · 三表实时同步）

与测试版仓库共用同一个 Google 在线《暗号表》（Spreadsheet ID: `11HHwGX4lCUyHmBjcdrWhmGUtZsYmwlwoxIE4Qh_aKFU`），实现 **总表 + 短链 + 团队** 三表打通实时联动。

## 核心同步规则

1. **唯一准绳（「团队」工作表）**：以在线表格「团队」表第 3 行起的在册组员名单为准。一旦表格中删除某成员或某条暗号，前端与云端总表/短链会同步剔除，绝不残留旧数据。
2. **三表打通查询**：
   - `总表`：`A1 姓名 | B1 关键词 | C1 平台/模板`（按 `番号 → 聊天 → 走光 → 任务 → 新模版 → 备用 → 备用2 → 创新` 固定顺序排列）
   - `短链`：`A1 姓名 | B1 短链 | C1 地址`
   - `团队`：7 大团队分组与在册人员名单
3. **纯静态与多端支持**：
   - 支持 Vercel 纯静态托管、GitHub Pages 自动部署、本地 Live Server 直接打开或双击 `start.bat` 启动（`node main.js`）。
   - 配套云端脚本位于 `apps-script/Code.gs`（已部署并与《暗号表》绑定联动）。
